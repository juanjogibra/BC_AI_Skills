# APIs estándar de Business Central (inventario real, BC 29.1 ES, 18/11/2026)

Obtenido del propio entorno: `GET .../api/v2.0/apicategoryroutes` (rutas) + `GET .../api/<ruta>/$metadata` (EntitySet). Repetirlo tras cada versión mayor: es la fuente de verdad, no la documentación.
Uso: `Invoke-BCApi "companies(<id>)/<entidad>" -Query '$filter=...' -Api '<ruta>'` (por defecto `v2.0`).
**Tabla origen de cada entidad (523 filas): [apis-tablas.md](apis-tablas.md).** Ojo: el error `... Execute: _Exclude_APIV2_` NO es un conjunto de permisos: `_Exclude_APIV2_` es el nombre de la extensión de Microsoft que publica la API v2.0 (páginas 300xx); el 403 indica que faltan permisos en BC para ejecutar sus páginas.
Todas las rutas incluyen además: `apicategoryroutes, companies, entityDefinitions, externalbusinesseventdefinitions, externaleventsubscriptions, subscriptions` (omitidas abajo).
