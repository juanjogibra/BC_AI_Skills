# Plantilla: diario de casos reales (el diario real va en privado/casos-reales.md, que no se sube)

Una entrada por incidencia resuelta o desarrollo probado o revisado. Solo hechos confirmados. Las más recientes arriba.
Cuando un caso revele algo que se puede repetir, llevarlo también a `patrones.md` (y citar aquí el nº de patrón).

Formato:
```
### dd/mm/aaaa · <cliente> · <incidencia | desarrollo | revisión> · <título corto>
- Síntoma / objetivo:
- Causa (clase: configuración | datos | estándar | personalización | permisos):
- Solución / resultado:
- Qué funcionó para llegar rápido (caso de éxito):
- Qué sobró o se podría haber evitado:
- Patrón: T#/B#/C# (nuevo o reforzado)
```
